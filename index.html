What you get

One engine, one theme

Chapters A rail on the left in landscape, along the bottom in portrait, one accent per chapter.
Presenter Notes, next slide, elapsed time and the exercise timer in a second window.
Print One slide per page, every step revealed, mixed orientations paginated at their own size.

Build it

pandoc + PyYAML

# every example
bash authoring/build_examples.sh

# one deck
python3 authoring/build_deck.py examples/keynote/deck.md

# a public copy, notes removed
python3 authoring/build_deck.py deck.md --public

Only deck.md and an optional custom.css live in the repo. The HTML is generated. The engine itself has no dependencies and opens from file://.
