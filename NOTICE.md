# Notice and provenance

## Origin

The slide engine in this repository is adapted from Dylan Davis's
AI-Foundations deck:

<https://github.com/D-Squared70/AI-Foundations>

The course decks built on it (The Human Edge, ERS, Copilot in Practice) extend
it with chapter navigation, a presenter window, an exercise timer, print
layout, a configurable canvas and a Markdown authoring front end.

## Permission

On 1 November 2026, Michael Borck asked Dylan Davis on LinkedIn for permission
to keep using and adapting the engine, with credit and a link in each repo, and
suggested licensing it under MIT or CC BY 4.0.

Dylan Davis replied:

> Feel free to use it. Thanks for letting me know

The screenshot and a transcript of the exchange are kept in
[`docs/permission/`](docs/permission/).

The original repository has no licence file, so this permission is the basis
for distributing the adapted engine. We credit Dylan Davis and link to the
original in the README and in each deck repository.

## Visual language

The default theme follows the visual language of the "Broken Ladder" deck
named in the original course stylesheet: dark stage, one accent per chapter,
serif titles, mono labels and SVG figures. Attribution for that visual language
is to be confirmed.

## Fonts

The default theme names Domine, Funnel Sans and Nanum Gothic Coding. These are
SIL Open Font Licence fonts. They are not bundled here; load them locally or use
the fallback stacks in `theme/tokens.css`.
