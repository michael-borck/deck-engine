# Prompt to *Workflow*

A half-day workshop. One task, one prompt, one workflow you can run on Monday.

::: notes
Set the frame in one line: we are not learning prompt tricks, we are making one
piece of work repeatable.
:::

## Three blocks. *One workflow.*

| Block | What you do | Output |
|---|---|---|
| Open | Pick one real task | A written brief |
| Build | Draft, test, revise | A working prompt |
| Share | Run it on a second case | A workflow card |

::: {.foot}
**The rule:** no generic examples. Use your own work.
:::

::: notes
Ask people to open the document they will use. If they have nothing, pair them
with someone who does.
:::

## Write the brief *before* the prompt.

::: {.exgrid}
::: {.steps}
1. Name the task and the reader.
2. Write the context the tool cannot guess.
3. Name the check that decides if the output is good.
:::

::: {.card .hi}
::: {.lab .a}
Test
:::

Give the brief to a partner. Can they produce the same output without asking you
a question? If not, the brief is not finished.
:::
:::

::: notes
Start the timer with T. Circulate and read the briefs upside down. The failures
are usually missing context, not missing prompt cleverness.
:::

The template

## Four lines. *Every time.*

```text
Task:     what to produce, for whom
Context:  what the tool cannot know
Format:   length, shape, audience
Check:    what makes the answer acceptable
```

::: {.foot}
Save it. The next prompt starts from this, not from a blank box.
:::

::: notes
Copy this onto the whiteboard and leave it there for the rest of the day.
:::

## One task. *One check.*

::: {.card .hi}
Name the task. Name the check. Run it three times on real work before you trust
it.

A workflow is a prompt you have tested, with a person still deciding.
:::

Portrait slide: useful for a phone-sized takeaway or a printed card. The same
deck can mix orientations.
