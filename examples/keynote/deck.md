## Ask Copilot about your email.

Same account. Same day. Two different answers.

::: {.row .c2}
::: {.card .dim .st reveal=1}
::: {.lab}
Copilot Chat · browser
:::

"I don't have access to your inbox."

Web context plus whatever you give it.
:::

::: {.card .hi .st reveal=2}
::: {.lab .a}
Copilot in Outlook · pane open
:::

"Here is what I can see in this thread: three decisions the client is asking for."

The email you selected is the context.
:::
:::

::: {.foot .st reveal=3}
**That gap is the session.** Not a limitation to wait out. A place where you decide what the tool sees.
:::

next block. The room's own experience is the curriculum.

The second trap

## Sharp where you know. *Trusting where you don't.*

::: {.row .c2}
::: {.card .st reveal=1}
::: {.lab}
In your own field
:::

### You catch its errors straight away.

"That's not how our contracts work." "That figure is from last year."
:::

::: {.card .hi .st reveal=2}
::: {.lab .a}
Outside it
:::

### The market, the law, the numbers.

Same tool, same error rate. But it reads as fact, because you cannot see the mistakes.
:::
:::

::: notes
This is Gell-Mann amnesia. Be most sceptical where you know least. Ask for one
example from the room of an AI answer they could not check.
:::

## AI is a multiplier. *What are you multiplying?*

A multiplier scales whatever you feed it, including the flaws.

> Clear context. Verified data. A named check. The same tool now extends reach
> instead of accelerating a mistake.

::: {.foot}
**The useful question is not what AI removes, but what it multiplies.**
:::

::: notes
Take two answers from the room: one weak input and one strong input. Bridge to
the next exercise.
:::

## Your pass first. *Then AI's.*

::: {.exgrid}
::: {.steps}
1. Sketch your own plan. Five minutes, no AI.
2. Give the tool the same task, unedited.
3. Compare side by side. Where did you beat it? Where did it beat you?
:::

::: {.stack}
::: {.mat}
::: {.card}
::: {.lab .a}
The task
:::

I manage a team of eight. One strong performer has been missing deadlines for a
month. Write me a plan to address this.
:::

::: {.out}
**OUTPUT** Where you beat it, where it beat you, and one thing it got confidently wrong.
:::
:::

::: {.deb}
::: {.card .hi}
::: {.lab .a}
Debrief
:::

Where did you beat it? That is your value. Name it.

Where did it beat you?

Did either tool ask what you already know?
:::
:::
:::
:::

::: notes
Circulate. Watch for people who skip their own pass. The debrief is the point,
not the output. Use T to start the timer; R resets it.
:::
